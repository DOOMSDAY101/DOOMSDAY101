## ⟡ About

I'm a Full Stack Software Engineer who lives at the intersection of **production backend systems** and **AI agent engineering**. I build scalable REST APIs and distributed backend systems with Node.js, NestJS, and Spring Boot — and I ship LLM-powered tools that people actually use, like an open-source debugging agent built on LangChain, LangGraph, and hybrid RAG.

### 🐛 [BugTrace](https://github.com/DOOMSDAY101/bugtrace)
**AI Debugging Agent** · `Python` `LangGraph` `RAG`

An open-source CLI debugging assistant powered by a LangGraph ReAct agent with tool-calling — lets developers interactively debug codebases in natural language.

- Hybrid RAG: BM25 keyword search + ChromaDB vector search + cross-encoder reranking
- Real-time token streaming with live markdown rendering in-terminal
- Redesigned agent prompting to fix over-eager tool invocation
